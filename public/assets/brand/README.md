# Griha Mart brand assets

`griha-mart-logo.png` is the original PNG supplied by the owner through their desktop clipboard. It has not been redrawn or generated. Circular presentation is applied with CSS.

Brand direction: green, orange, white, with restrained blue from the shopping cart in the logo. Nepali name: गृह मार्ट. Brand line: घरका लागि सबै कुरा.
